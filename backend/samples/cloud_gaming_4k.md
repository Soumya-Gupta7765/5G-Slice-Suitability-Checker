# Cloud Gaming Trial — Network Requirements

**Product:** "Arcade Cloud" streaming service, pilot with 5,000 households.

## Summary

We want to let players launch console-quality titles on a TV stick without a
console. The pilot also bundles an on-demand movie catalogue including 4K films,
so the marketing team keeps calling the offering "4K entertainment".

## Connectivity expectations

- Players are very sensitive to input lag. The experience should feel like a
  local console, so the network needs low latency.
- Picture quality: 4K HDR at 60 fps for the movie catalogue.
- The service must be highly reliable during evening peak hours.
- A single household runs one session at a time; the pilot targets 5,000
  concurrent households.

## Open questions from the product team

The engineering team has not yet agreed how much spectrum the operator should
allocate per household, and nobody has measured the actual bitrate per game
title. Please size the slice using the stated targets and flag what is missing.
